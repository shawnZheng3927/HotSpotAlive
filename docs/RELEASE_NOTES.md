HotSpotAlive 是原生 macOS 菜单栏热点保活工具。

- 下载 `Universal.dmg`，打开后将应用拖入“应用程序”。
- 支持 macOS 13 及以上，包含 Intel 和 Apple Silicon 两种原生架构。
- 菜单栏仅显示 `HSA 开` / `HSA 关`。
- Wi-Fi 有收发活动时跳过保活，默认连续空闲 25 秒才发出微量 DNS 查询。
- 支持登录启动、可选防止自动睡眠、透明圆角图标。
- 附 ZIP 便携包、源码包和 SHA-256 校验文件。

此版本使用临时签名，尚未通过 Apple 开发者公证。首次打开若被拦截，请参考 [Apple 官方说明](https://support.apple.com/102445)。保活效果取决于 iPhone 和网络环境。
